2026-10-22 · Multi-Sector Parallel Fan-Out, Argon Substrate & Native Vector Telemetry0.3.0
  • New: Multi-Sector Parallel Fan-Out Engine: Real-time cross-sector intelligence decomposing compound queries into concurrent parallel sub-tasks across 15+ industry sectors and GICS benchmarks (XLK, XLE, XLV, XLF, XLI, ITA, SMH, BTC-USD) in under 1 second.
  • New: Batch Multi-Asset Market Telemetry: Live Yahoo Finance chart data fetching with comparative markdown tables, day trading ranges, volume, and automatic direction pills.
  • New: Gemini 4 Argon Multi-Agent Substrate: Self-healing orchestration layer configured in config.yml and bridged via backend/argon_bridge.py.
  • New: Native Vector Synthesis (SVG): Standalone vector telemetry renderer (Tools/Visualizer.js) compiling dark-mode SVG telemetry maps into public/generated/visuals/live_drift_map.svg.
  • New: Shannon Entropy Loop Defense: Real-time entropy evaluator calculating token diversity and halting recursive degradation ($H(X) \ge 0.88$) with zero-locking SQLite-WAL persistence.
2026-10-17 · Contract drift gate, trust pages0.2.0
  • New: sarembok audit now compares the live contract against a committed baseline and exits 1 on breaking changes (removed endpoints, removed or retyped response fields). Additive changes are reported, never fatal.
  • New: ?fresh=1 on /api/spec bypasses the 30-minute cache; the audit command always uses it.
  • New: real status, security and changelog pages.
  • Mobile: menu and bottom-sheet panels for phones (2a95ec3).
  • Fixed: unknown URLs returned 200 with the app shell; they now return 404.

Corrections. Before this release the "audit" command only checked that extraction succeeded and printed "Zero contract regressions" without comparing anything. That output was misleading and has been replaced. The "100% Deterministic" label on spec was also removed; it only indicated that extraction returned a result.
