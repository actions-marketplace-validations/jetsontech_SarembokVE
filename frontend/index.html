Headless Specification REST API

The headless REST API allows automated audit scripts, CLI tools, and CI runners to extract OpenAPI 3.1 definitions and TypeScript interfaces with zero browser overhead.

GET /api/spec?target=https://target.com

# Direct file downloads:
GET /api/spec/export?target=https://target.com&format=openapi
GET /api/spec/export?target=https://target.com&format=typescript

Caddy Edge Security & Isolation

All incoming traffic terminates at the Caddy reverse proxy on ports 80/443 with TLS 1.3. Internal container port 9000 is never bound to the public host interface, preventing direct access and enforcing rate limiting, HSTS, and strict origin validation.
