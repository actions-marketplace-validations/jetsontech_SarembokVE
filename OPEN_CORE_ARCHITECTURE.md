# SarembokVE Open-Core & Commercial Architecture

This public repository contains the **SarembokVE GitHub Marketplace Action, CLI tool, and core engine pipeline**.

### Proprietary Enterprise Modules (`SarembokVE-Enterprise`)
To protect commercial intellectual property, the following production cloud and OS components are maintained separately:
* **Sovereign Cloud Control Plane (`server.py` & `Deployment/cloud/`)** - Multi-region orchestration
* **Multi-Model Cognitive Router & Backend (`backend/` & `AI/`)** - Hosted multi-LLM inference grid
* **Sarembok OS & Digital-Human Embodiment (`sarembok-os/` & `labs/unreal/`)** - Real-time spatial engine
