## Operating rule
The Git repository contains the canonical, version-controlled copies. Decisions are added as EDRs; superseding decisions reference prior EDRs rather than silently rewriting history.

## Versioning
Use semantic/document versions for major blueprint changes. Keep dated EDRs immutable after acceptance except for metadata corrections.
